# KrishiRakshak - Agricultural Marketplace Frontend

A modern, human-designed agricultural marketplace platform for connecting farmers, buyers, and transporters directly.

## 📄 Pages Created

### 1. **index.html** - Landing/Home Page
- Hero section with CTA buttons
- Problem statement (3 main challenges)
- Platform overview (4 user roles)
- How it works (4-step process)
- 6 core features
- Mobile app section
- Impact statistics
- Success stories (testimonials)
- FAQ section
- Footer with links

### 2. **blog.html** - Blog & News Page
- Recent farming tips, market updates, success stories
- 6 blog posts with categories, dates, excerpts
- Sidebar with:
  - Category filter
  - Popular posts
  - Newsletter signup
- Responsive grid layout
- Direct navigation to other pages

### 3. **dashboard.html** - Farmer Dashboard
- Logged-in farmer view
- Left sidebar navigation
- 4 key statistics:
  - Active listings count
  - Monthly earnings
  - Seller rating
  - Successful deals
- Recent buyer offers table
- Active crop listings with:
  - Quantity available
  - Asking price
  - Number of offers received
  - Edit/Remove options
- "Add New Listing" button

### 4. **pricing.html** - Pricing Plans
- 3 pricing tiers:
  - **Starter** (Free) - Basic features
  - **Professional** (₹299/month) - Most popular, featured card
  - **Enterprise** (Custom) - For SHGs & FPOs
- Feature comparison table
- Monthly/Yearly toggle
- CTA buttons for each plan
- No commission guarantee banner

## 🎨 Design Features
- **Modern & Organic:** Avoids AI-generated look
- **Consistent Branding:** Forest green primary color (#16a34a)
- **Responsive:** Works on desktop, tablet, mobile
- **Human Language:** Natural, conversational copy
- **Accessible:** Proper semantic HTML, keyboard navigation
- **Fast:** Minimal external dependencies, optimized code

## 🚀 Quick Start
1. Open `index.html` in a browser to view the landing page
2. Click "Blog" to see the blog page
3. Click "Dashboard" to see the farmer dashboard
4. Click "Pricing" to see pricing plans
5. All pages are fully functional and cross-linked
