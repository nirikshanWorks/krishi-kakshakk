## 🚀 Getting Started (Quick Steps)

### 1️⃣ Get API Keys (5 minutes)
- Google Gemini: https://makersuite.google.com/app/apikey
- OpenWeatherMap: https://openweathermap.org/api

### 2️⃣ Install Backend (2 minutes)
```bash
cd backend
npm install
# Add .env with API keys
npm start
```

### 3️⃣ Install Frontend (2 minutes)
```bash
cd frontend
npm install
npm start
```

### 4️⃣ Use Application (1 minute)
- Open http://localhost:3000
- Fill the form
- Get recommendations!
